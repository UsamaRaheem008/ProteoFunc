1. WHAT THIS PROJECT IS
================================================================================

ProteoFunc is a multimodal deep learning framework for predicting the biological
functions of proteins. It is an MSc Bioinformatics research project that combines
two types of biological information:

  (A) Protein SEQUENCE information  -  the amino acid sequence of a protein, which
      determines its 3D structure and ultimately its function. This is processed
      using a pre-trained protein language model called ESM-2, developed by
      Meta/Facebook AI Research.

  (B) Protein-Protein INTERACTION (PPI) NETWORK information  -  the network of
      known physical and functional interactions between proteins. If two proteins
      interact, they often share related functions. This is processed using a
      Graph Neural Network called GraphSAGE.

The project fuses these two modalities (sequence + network) together using an
attention-based fusion mechanism to produce predictions of Gene Ontology (GO)
functional annotations  -  standardized labels that describe what a protein does.

In simpler terms: you give it a protein, and it tells you what that protein
does in the cell (e.g., "binds DNA", "catalyzes ATP hydrolysis", "located in
the nucleus", "involved in apoptosis", etc.).

================================================================================
2. THE PROBLEM IT SOLVES
================================================================================

The Problem:
  - There are millions of known protein sequences, but most of them have NO
    experimentally verified functional annotations.
  - Experimentally determining protein function is slow and expensive.
  - Only ~0.5% of proteins in UniProt have manually curated GO annotations.
  - Computational prediction of protein function is therefore essential.

Why Multimodal?
  - Sequence-only methods (like BLAST or basic neural networks) miss context
    about how proteins interact in biological networks.
  - Network-only methods miss the biochemical properties encoded in the sequence.
  - By combining BOTH sequence features AND network context, the multimodal
    approach captures complementary information, leading to better predictions.

What Makes This Project Different:
  - Uses state-of-the-art protein language model (ESM-2) instead of hand-crafted
    sequence features.
  - Uses GraphSAGE for scalable graph learning on PPI networks.
  - Provides five different fusion mechanisms for combining modalities.
  - Includes full explainability analysis (attention maps, integrated gradients).
  - Comes with an interactive web dashboard for real-time predictions.
  - Uses CAFA-standard evaluation metrics for rigorous benchmarking.

================================================================================
3. HOW IT WORKS (HIGH-LEVEL)
================================================================================

The overall pipeline is:

  Step 1: Download Data
    - Download protein sequences from UniProt (up to 15,000 human proteins)
    - Download protein interaction data from STRING database
    - Download Gene Ontology (GO) term definitions

  Step 2: Process Data
    - Filter proteins by sequence length (50-1200 amino acids)
    - Filter GO terms by annotation frequency (30-5000 proteins per term)
    - Map protein identifiers between databases

  Step 3: Extract Features
    - Run ESM-2 protein language model to convert each amino acid sequence into
      a 320-dimensional numerical vector (embedding)
    - Build PPI graph in PyTorch Geometric format with ESM-2 embeddings as
      node features

  Step 4: Train Models
    - Train three model variants: sequence-only, network-only, multimodal
    - Use Focal Loss to handle class imbalance
    - Apply early stopping and learning rate scheduling

  Step 5: Evaluate
    - Compute CAFA-standard metrics (F-max, S-min, AUPR, AUROC, etc.)
    - Perform stratified analysis by GO namespace, hub status, connectivity
    - Run statistical significance tests between models

  Step 6: Explain
    - Extract attention weights to understand modality contributions
    - Use Integrated Gradients for feature importance analysis

  Step 7: Deploy
    - Launch interactive Streamlit dashboard for live predictions

The architecture in diagram form:

  Protein Sequence ──► ESM-2 (8M params) ──► SequenceEncoder ──┐
                                                                 ├── AttentionFusion ──► Classifier ──► GO Terms
  PPI Graph ──────────► GraphSAGE ──────────► GraphEncoder ─────┘

4. DATA SOURCES AND WHAT THEY PROVIDE
================================================================================

(A) UniProt (Universal Protein Resource)
    - Source: https://www.uniprot.org
    - What it provides: Protein sequences and their known GO annotations
    - Settings used:
        * Organism: Homo sapiens (human, taxonomy ID 9606)
        * Reviewed proteins only (Swiss-Prot, manually curated)
        * Maximum 15,000 proteins
        * Sequence length: 50 to 1200 amino acids
    - What we extract: Amino acid sequences, accession IDs, GO annotations

(B) STRING (Search Tool for the Retrieval of Interacting Genes/Proteins)
    - Source: https://string-db.org
    - What it provides: Protein-protein interaction network
    - Settings used:
        * Version: 12.0
        * Species: Human (9606)
        * Confidence threshold: 0.7 (high confidence interactions only)
        * Both physical and functional interactions
    - What we extract: Interaction edges with confidence scores

(C) Gene Ontology (GO)
    - Source: http://geneontology.org
    - What it provides: Standardized vocabulary for protein functions
    - Three namespaces:
        * MF (Molecular Function): What the protein does biochemically
          Examples: "ATP binding", "DNA binding", "kinase activity"
        * BP (Biological Process): The larger biological program
          Examples: "apoptosis", "cell division", "signal transduction"
        * CC (Cellular Component): Where the protein is located
          Examples: "nucleus", "cytoplasm", "mitochondrial membrane"
    - Settings used:
        * Minimum 30 proteins annotated per GO term
        * Maximum 5000 proteins annotated per GO term
    - This is a multi-label classification problem: each protein can have
      MULTIPLE GO terms across all three namespaces.

5. COMPLETE MODEL ARCHITECTURE (TECHNICAL DETAILS)
================================================================================

The multimodal model (called SPFP  -  Sequence-PPI Fusion Predictor) has four
main components:

--- COMPONENT 1: Sequence Encoder ---
  - Input: ESM-2 embedding (320-dimensional vector per protein)
  - Architecture: LayerNorm -> Linear(320->320) -> GELU activation
  - Output: 320-dimensional encoded sequence representation
  - Purpose: Projects raw ESM-2 embeddings into a task-specific space
  - Dropout: 0.2 (half of classifier dropout)

--- COMPONENT 2: Graph Encoder (GraphSAGE) ---
  - Input: PPI graph with ESM-2 embeddings as node features
  - Architecture: 2-layer GraphSAGE with mean aggregation
    * Layer 1: 320 -> 256 dimensions
    * Layer 2: 256 -> 256 dimensions
    * Batch normalization after each layer
    * Residual connections
  - Neighbor sampling: [25, 10] (25 neighbors in first hop, 10 in second)
  - Output: 256-dimensional graph-aware protein representation
  - Purpose: Captures protein interaction network context  -  if your neighbors
    in the PPI network have certain functions, you likely do too
  - Dropout: 0.225 (75% of classifier dropout)

--- COMPONENT 3: Fusion Module ---
  - Input: Sequence embedding (320-dim) + Graph embedding (256-dim)
  - Default method: Attention-based fusion (4 heads)
  - Architecture:
    * Projects both modalities to same dimension (320)
    * Stacks them as [seq_proj, net_proj] -> shape (B, 2, 320)
    * Attention network: Linear(320->160) -> Tanh -> Linear(160->1)
    * Softmax over the 2 modalities -> attention weights
    * Weighted sum: fused = α * seq + (1-α) * net
    * LayerNorm + Dropout
  - Output: 320-dimensional fused representation
  - Interpretability: Per-protein attention weights show how much the model
    relies on sequence vs. network for each individual protein
  - Dropout: 0.1 (quarter of classifier dropout)

--- COMPONENT 4: Classification Head ---
  - Input: 320-dimensional fused embedding
  - Architecture: MLP with two hidden layers:
    * Linear(320->256) -> GELU -> LayerNorm -> Dropout(0.4)
    * Linear(256->128) -> GELU -> LayerNorm -> Dropout(0.4)
    * Linear(128->C) where C = number of GO terms
  - Output: C logits (one per GO term), then sigmoid -> probabilities
  - Purpose: Maps fused representation to multi-label GO predictions

================================================================================
6. THE THREE MODEL VARIANTS AND WHY
================================================================================

This project trains and compares THREE model variants to demonstrate the
value of multimodal learning:

(1) SEQUENCE-ONLY MODEL
    - Uses: ESM-2 embeddings ONLY
    - Architecture: SequenceEncoder -> Classifier
    - Purpose: Baseline showing what sequence information alone can achieve
    - When it excels: Proteins with distinct sequence motifs (enzymes,
      DNA-binding proteins, etc.)

(2) NETWORK-ONLY MODEL
    - Uses: PPI graph (GraphSAGE) ONLY
    - Architecture: GraphSAGEEncoder -> Classifier
    - Purpose: Baseline showing what network topology alone can achieve
    - When it excels: Hub proteins with many high-confidence interactions,
      proteins in well-characterized complexes

(3) MULTIMODAL MODEL (SPFP  -  the main model)
    - Uses: ESM-2 embeddings + PPI graph TOGETHER
    - Architecture: SequenceEncoder + GraphSAGEEncoder -> Fusion -> Classifier
    - Purpose: Demonstrates that combining both modalities is superior
    - When it excels: Most proteins, especially those with both distinctive
      sequences AND significant network context

The expected ranking of performance is:
  Multimodal > Sequence-Only > Network-Only

This validates the research hypothesis that multimodal integration improves
protein function prediction.

7. FUSION MECHANISMS (5 TYPES)
================================================================================

The project implements FIVE different fusion mechanisms. The default is
"attention" but all can be selected via config:

(1) CONCATENATION FUSION
    - Simply concatenates [sequence_emb; network_emb]
    - Linear projection to output dimension
    - No interpretable weights (assumes 50/50 contribution)
    - Simplest but least flexible

(2) WEIGHTED SUM FUSION
    - Projects both modalities to same dimension
    - Learns a single scalar weight α (sigmoid-bounded)
    - fused = α * seq + (1-α) * net
    - One global weight for all proteins

(3) ATTENTION FUSION (DEFAULT  -  Most Interpretable)
    - Projects both modalities to same dimension
    - Learns PER-PROTEIN attention weights via neural network
    - Each protein gets its own α based on its embeddings
    - Most interpretable: shows which modality matters more per protein
    - Key insight: some proteins depend more on sequence, others on network

(4) GATED FUSION
    - Uses a gating network: gate = σ(W . [seq; net] + b)
    - fused = gate * seq + (1-gate) * net
    - Gate is element-wise (per-dimension), not per-modality
    - Offers fine-grained control over information flow

(5) CROSS-MODAL ATTENTION FUSION
    - Uses multi-head attention (4 heads)
    - Sequence attends to network context (what network info is relevant?)
    - Network attends to sequence features (what sequence info is relevant?)
    - Combines both cross-attended representations
    - Most complex, captures inter-modal dependencies

8. FULL PIPELINE STAGES (STEP BY STEP)
================================================================================

STAGE 1: EMBEDDINGS (ESM-2 Feature Extraction)  -  ~5 minutes
  - Loads the ESM-2 protein language model (facebook/esm2_t6_8M_UR50D)
  - For each protein sequence:
    * Tokenizes the amino acid sequence
    * Passes through ESM-2 (6 transformer layers, 8M parameters)
    * Mean-pools the hidden states (excluding special tokens)
    * Produces a 320-dimensional embedding vector
  - Saves all embeddings as a NumPy array
  - Output: data/embeddings/esm2_embeddings.npy

STAGE 2: GRAPH CONSTRUCTION (PPI Network)  -  ~5 minutes
  - Loads STRING interaction data
  - Maps STRING protein IDs to UniProt accession IDs
  - Filters interactions by confidence threshold (>=0.7)
  - Computes network statistics:
    * Degree centrality (how many connections each protein has)
    * Betweenness centrality (how often a protein sits on shortest paths)
    * Closeness centrality (how close a protein is to all others)
  - Identifies hub proteins (highly connected nodes)
  - Creates PyTorch Geometric Data object with:
    * Node features: ESM-2 embeddings (320-dim per node)
    * Edge index: sparse connectivity matrix
    * Edge weights: STRING confidence scores
  - Outputs:
    * data/processed/pyg_graph_data.pt (graph structure)
    * data/processed/network_statistics.json (centrality metrics)
    * data/processed/hub_status.pkl (hub protein flags)
    * data/processed/centrality_metrics.pkl (per-protein centrality)

STAGE 3: DATASET ASSEMBLY  -  ~2 minutes
  - Combines embeddings, GO term labels, and graph indices
  - Creates train/validation/test split: 70% / 15% / 15%
  - Stratified splitting to preserve label distribution
  - Computes class weights to handle label imbalance
  - Output: data/processed/split_data.pkl

STAGE 4: MODEL TRAINING  -  ~30-60 minutes
  - Trains all three model variants sequentially:
    1. sequence_only
    2. network_only
    3. multimodal
  - For each model:
    * Builds model architecture
    * Initializes AdamW optimizer (lr=1e-4, weight_decay=1e-5)
    * Sets up cosine learning rate schedule with 5-epoch warmup
    * Trains for up to 50 epochs with early stopping (patience=15)
    * Uses Focal Loss (γ=2, α=0.25) to handle class imbalance
    * Gradient clipping at max_norm=1.0
    * Validates after each epoch on validation set
    * Saves best checkpoint based on validation F-max
  - Outputs:
    * outputs/checkpoints/sequence_only_best.pt
    * outputs/checkpoints/network_only_best.pt
    * outputs/checkpoints/multimodal_best.pt
    * outputs/checkpoints/*_history.json (training curves)

STAGE 5: EVALUATION  -  ~5 minutes
  - Loads best checkpoint for each model
  - Runs inference on test set
  - Computes all CAFA-standard metrics
  - Performs stratified analysis by:
    * GO namespace (MF, BP, CC)
    * Hub status (hub vs non-hub proteins)
    * Network connectivity (high, medium, low degree)
    * Sequence homology groups
  - Runs statistical significance tests between models
  - Outputs:
    * outputs/evaluation/sequence_only/overall_metrics.json
    * outputs/evaluation/network_only/overall_metrics.json
    * outputs/evaluation/multimodal/overall_metrics.json
    * outputs/evaluation/model_comparison.csv

STAGE 6: EXPLAINABILITY  -  ~5 minutes
  - Extracts fusion attention weights from multimodal model
  - Generates modality contribution distribution plots
  - Identifies sequence-dependent vs network-dependent proteins
  - Computes Integrated Gradients for feature importance
  - Outputs:
    * outputs/explainability/modality_distribution.png
    * outputs/explainability/protein_attention.png
    * outputs/explainability/integrated_gradients.png

9. TRAINING DETAILS
================================================================================

Optimizer: AdamW
  - Learning rate: 1e-4 (0.0001)
  - Weight decay: 1e-5 (L2 regularization)
  - Betas: (0.9, 0.999)
  - Epsilon: 1e-8

Learning Rate Schedule: Cosine Annealing with Warmup
  - Warmup: 5 epochs (linearly increases LR from 0 to 1e-4)
  - After warmup: cosine decay to minimum LR of 1e-6
  - Total epochs: 50

Loss Function: Focal Loss
  - Purpose: Addresses severe class imbalance in GO annotation prediction
    (most GO terms apply to very few proteins, so negative examples dominate)
  - Formula: FL(p) = -α(1-p)^γ * log(p)
  - Gamma (γ): 2.0  -  down-weights easy (well-classified) examples
  - Alpha (α): 0.25  -  balances positive vs negative class importance
  - Effect: Forces the model to focus on hard-to-classify examples

Early Stopping:
  - Monitored metric: Validation F-max (protein-centric F1)
  - Patience: 15 epochs (stops if no improvement for 15 consecutive epochs)
  - Minimum delta: 1e-4 (improvement must be at least this much)
  - Restores best weights on stop

Gradient Clipping:
  - Max norm: 1.0  -  prevents exploding gradients

Mixed Precision Training:
  - Enabled by default for faster training on GPU
  - Uses PyTorch AMP (Automatic Mixed Precision)

Batch Size: 64

Reproducibility:
  - Random seed: 42 (fixed for all random operations)
  - Deterministic mode enabled

10. ALL RESULTS AND METRICS THIS PROJECT PRODUCES
================================================================================

This project computes the following metrics for each model variant:

--- CAFA-STANDARD METRICS (Primary) ---

(1) F-max (Maximum F-measure)
    - THE primary metric for protein function prediction
    - Defined by the Critical Assessment of Functional Annotation (CAFA)
    - Computes protein-centric F1 at every threshold from 0.01 to 0.99
    - Reports the maximum F1 achieved across all thresholds
    - Range: 0.0 to 1.0 (higher is better)
    - Also reports the optimal threshold at which F-max is achieved
    - This is the metric that early stopping monitors

(2) S-min (Minimum Semantic Distance)
    - CAFA-standard ontology-aware metric
    - Measures remaining uncertainty after prediction
    - Weighted by Information Content (IC) of GO terms
      (rare terms have higher IC, so missing them is penalized more)
    - Formula: S = sqrt(RU² + MI²) where
      RU = remaining uncertainty (weighted false negatives)
      MI = misinformation (weighted false positives)
    - Range: 0.0 to ∞ (LOWER is better)
    - A model that predicts everything wrong has high S-min
    - A model that predicts perfectly has S-min ~ 0

(3) AUPR (Area Under Precision-Recall Curve)
    - Macro-averaged across all GO term classes
    - More informative than AUROC for imbalanced datasets
    - Range: 0.0 to 1.0 (higher is better)
    - A random classifier achieves AUPR ~ prevalence of positive class

(4) AUROC (Area Under Receiver Operating Characteristic Curve)
    - Macro-averaged across all GO term classes
    - Measures discrimination ability regardless of threshold
    - Range: 0.0 to 1.0 (higher is better, 0.5 = random)

--- STANDARD ML METRICS ---

(5) Micro F1
    - Computes F1 globally across all labels and proteins
    - Each prediction (protein x GO term) is treated equally
    - More influenced by frequent GO terms
    - Range: 0.0 to 1.0

(6) Macro F1
    - Computes F1 per GO term, then averages
    - Treats rare and common GO terms equally
    - Usually lower than Micro F1 for imbalanced data
    - Range: 0.0 to 1.0

(7) Micro Precision
    - Fraction of positive predictions that are correct (globally)
    - Range: 0.0 to 1.0

(8) Micro Recall
    - Fraction of true labels that are correctly predicted (globally)
    - Range: 0.0 to 1.0

(9) Hamming Loss
    - Fraction of all (protein x GO term) pairs that are wrong
    - Includes both false positives and false negatives
    - Range: 0.0 to 1.0 (LOWER is better)

--- TOP-K ACCURACY ---

(10) Top-5 Accuracy
    - For each protein, checks if at least one of the top-5 predicted GO
      terms is a true annotation
    - Range: 0.0 to 1.0

(11) Top-10 Accuracy
    - Same as above but with top-10 predictions
    - Range: 0.0 to 1.0

(12) Top-20 Accuracy
    - Same as above but with top-20 predictions
    - Range: 0.0 to 1.0

--- PER-CLASS (PER-GO-TERM) METRICS ---

For each individual GO term, the project computes:
  - Per-class AUROC
  - Per-class AUPR
  - Per-class F1
  - Per-class Precision
  - Per-class Recall
  - Support (number of positive examples)

--- STRATIFIED ANALYSIS ---

All main metrics are also broken down by:

  (a) GO Namespace:
      - Molecular Function (MF) performance
      - Biological Process (BP) performance
      - Cellular Component (CC) performance
      Expectation: CC is usually easiest, MF harder, BP hardest

  (b) Hub Status:
      - Hub proteins (highly connected in PPI network)
      - Non-hub proteins (few connections)
      Expectation: Network-based models do better on hub proteins

  (c) Network Connectivity:
      - High-degree proteins (many interactions)
      - Medium-degree proteins
      - Low-degree proteins
      Expectation: Multimodal advantage is greatest for high-degree proteins

  (d) Sequence Homology Groups:
      - Proteins grouped by sequence similarity
      Expectation: Sequence-based models do well on proteins with known homologs

--- STATISTICAL SIGNIFICANCE TESTS ---

  (a) Paired t-test between each pair of models
  (b) Wilcoxon signed-rank test (non-parametric)
  (c) Cohen's d effect size
  (d) Bootstrap 95% confidence intervals (1000 iterations)
  (e) Bonferroni correction for multiple hypothesis testing

12. EVALUATION AND STATISTICAL ANALYSIS
================================================================================

The evaluation module provides rigorous, publication-quality assessment:

(A) OVERALL MODEL COMPARISON
    - All three models are evaluated on the SAME held-out test set (15% of data)
    - The model_comparison.csv file presents all metrics side by side
    - Expected result: Multimodal achieves highest F-max, lowest S-min

(B) STRATIFIED ANALYSIS
    - Reveals WHERE each model excels and struggles
    - By namespace: MF/BP/CC have different prediction difficulty
    - By hub status: Network models benefit from hub proteins
    - By connectivity: Shows the value of PPI information

(C) STATISTICAL SIGNIFICANCE
    Paired t-test:
      - Tests if mean F1 difference between two models is significant
      - Reports t-statistic and p-value
      - A p-value < 0.05 means the improvement is statistically significant

    Wilcoxon signed-rank test:
      - Non-parametric alternative (doesn't assume normal distribution)
      - More robust for small sample sizes
      - Reports test statistic and p-value

    Bootstrap Confidence Intervals:
      - 1000 bootstrap samples to estimate 95% CI for each model's F1
      - If CIs don't overlap, difference is significant

    Bonferroni Correction:
      - Adjusts p-values for multiple comparisons
      - With 3 pairwise comparisons: corrected α = 0.05/3 = 0.0167

    Cohen's d (Effect Size):
      - Measures the magnitude of the difference, not just significance
      - d < 0.2: small effect
      - d = 0.5: medium effect
      - d > 0.8: large effect

(D) THE RESULTS TABLE LOOKS LIKE THIS:

    +------------------+-------+-------+------+-------+----------+----------+

13. EXPLAINABILITY AND INTERPRETABILITY
================================================================================

This project doesn't just make predictions  -  it explains WHY it makes them.

(A) FUSION ATTENTION WEIGHTS
    - For each protein, the attention fusion module outputs:
      * seq_weight: How much the model relies on sequence information (0 to 1)
      * net_weight: How much the model relies on network information (0 to 1)
      * seq_weight + net_weight = 1.0 always
    - Visualization: Histogram showing distribution across all test proteins
    - Key insight: Some proteins are "sequence-dependent" (high seq_weight)
      while others are "network-dependent" (high net_weight)
    - Biological interpretation:
      * Enzymes with unique catalytic sites -> sequence-dependent
      * Scaffold/adaptor proteins in complexes -> network-dependent
      * Signaling proteins -> balanced (both modalities contribute)

(B) PROTEIN-SPECIFIC ATTENTION ANALYSIS
    - Shows the top-20 most sequence-dependent proteins and their weights
    - Shows the top-20 most network-dependent proteins and their weights
    - Stacked horizontal bar chart: blue (sequence) + red (network) = 100%
    - Allows biological interpretation of individual predictions

(C) INTEGRATED GRADIENTS (IG)
    - A rigorous attribution method from the Captum library
    - Computes feature importance by integrating gradients along a path
      from a baseline (zero embedding) to the actual embedding
    - Shows which of the 320 embedding dimensions contribute most
      to each prediction
    - Heatmap visualization of feature importance
    - Settings: 50 integration steps for accuracy

(D) GNN EXPLAINER
    - Identifies which edges (protein interactions) in the PPI graph
      are most important for each prediction
    - Top-k edges and nodes are highlighted
    - Settings: 200 epochs, lr=0.01, top-10 edges, top-5 nodes

15. INFERENCE API (LIVE PREDICTION)
================================================================================

The project provides a Python API for programmatic predictions:

  from inference.predict import ProteinFunctionPredictor

  predictor = ProteinFunctionPredictor(
      model_type="sequence_only",
      checkpoint_path="outputs/checkpoints/sequence_only_best.pt",
      config_path="configs/config.yaml",
      threshold=0.3,      # minimum probability to report
      top_k=20,           # maximum predictions to return
  )

  result = predictor.predict("MEEPQSDPSVEPPLSQET...")

  # Access results:
  result.predictions          # List of predicted GO terms
  result.top_predictions      # Sorted by probability (descending)
  result.by_namespace()       # Grouped by MF/BP/CC
  result.inference_time       # Time taken in seconds
  result.embedding            # The ESM-2 embedding vector
  result.model_type           # Which model was used

Each prediction contains:
  {
    "go_id":       "GO:0003677",
    "go_name":     "DNA binding",
    "namespace":   "MF",
    "probability": 0.873,
    "rank":        1
  }

Features:
  - Automatic sequence validation (removes invalid characters)
  - Automatic ESM-2 embedding extraction (no pre-processing needed)
  - GO term names fetched from EBI QuickGO API
  - Batch prediction support for multiple sequences
  - Results exportable as CSV or JSON

18. CONFIGURATION AND CUSTOMIZATION
================================================================================

All settings are controlled via configs/config.yaml. Key adjustable parameters:

DATA SETTINGS:
  - Organism: Change from human to any species (with taxonomy ID)
  - Max proteins: Scale from 1,000 to 100,000+
  - Sequence length range: 50-1200 (adjustable)
  - STRING confidence threshold: 0.0-1.0 (0.7 default)
  - GO term annotation range: min 30, max 5000

MODEL SETTINGS:
  - ESM-2 model: 8M, 35M, 150M, 650M, or 3B parameters
  - GraphSAGE layers: 1 to 4
  - GraphSAGE hidden dim: 64 to 1024
  - Fusion method: concat, weighted_sum, attention, gated, cross_attention
  - Classifier hidden dims: configurable list
  - Dropout: 0.0 to 0.8

TRAINING SETTINGS:
  - Epochs: 1 to 500
  - Batch size: 8 to 512
  - Learning rate: configurable
  - Loss function: focal, bce, weighted_bce
  - Early stopping patience: 5 to 50
  - Gradient clipping: configurable

EVALUATION SETTINGS:
  - Threshold sweep range and step size
  - Top-K values for accuracy computation
  - Number of bootstrap samples for CI
  - Significance level (alpha)

19. EXPECTED RESULTS AND PERFORMANCE

Based on the architecture and methodology, the expected results are:

EXPECTED METRIC RANGES (approximate):
  +------------------+------------+----------+----------+---------+
  | Model            | F-max      | AUROC    | AUPR     | S-min   |
  +------------------+------------+----------+----------+---------+
  | Sequence Only    | 0.35-0.55  | 0.75-0.85| 0.20-0.40| 5.0-8.0 |
  | Network Only     | 0.25-0.45  | 0.65-0.80| 0.15-0.30| 6.0-10.0|
  | Multimodal       | 0.40-0.60  | 0.78-0.88| 0.25-0.45| 4.0-7.0 |
  +------------------+------------+----------+----------+---------+

  Note: Exact values depend on dataset size, ESM-2 model variant, and
  the specific proteins/GO terms in the dataset. The 8M parameter ESM-2
  model is used for efficiency but larger models may yield better results.

EXPECTED OBSERVATIONS:
  1. Multimodal > Sequence-Only > Network-Only (for F-max)
  2. Network model benefits most from hub proteins with many interactions
  3. Sequence model excels for proteins with unique sequence motifs
  4. Multimodal shows largest improvement on proteins with BOTH strong
     sequence features AND rich network context
  5. Cellular Component (CC) predictions are usually most accurate
  6. Biological Process (BP) predictions are usually hardest
  7. Molecular Function (MF) predictions are in between

KEY FINDINGS THE PROJECT DEMONSTRATES:
  1. Pre-trained protein language models (ESM-2) provide powerful
     representations that outperform hand-crafted sequence features
  2. PPI network context provides complementary information not
     captured by sequence alone
  3. Attention-based fusion allows the model to adaptively weight
     modalities per protein, which is more effective than fixed fusion
  4. The multimodal approach is statistically significantly better
     than either single-modality baseline
  5. Explainability analysis reveals biologically meaningful patterns
     in how the model uses different information sources

  - Graph construction: ~5 minutes
  - Dataset building: ~2 minutes
  - Model training (all 3): ~30-60 minutes (CPU), ~10-20 minutes (GPU)
  - Evaluation: ~5 minutes
  - Explainability: ~5 minutes
  - Total pipeline: ~1-1.5 hours

20. KEY RESEARCH CONTRIBUTIONS
================================================================================

This project makes the following contributions:

  1. MULTIMODAL ARCHITECTURE (SPFP): A novel architecture that combines
     protein language model embeddings with graph neural network representations
     through configurable attention-based fusion.

  2. COMPREHENSIVE COMPARISON: Systematic comparison of sequence-only,
     network-only, and multimodal approaches on the same dataset with
     the same evaluation protocol.

  3. INTERPRETABLE FUSION: The attention-based fusion mechanism provides
     per-protein interpretability, revealing which modality the model
     relies on for each prediction.

  4. CAFA-STANDARD EVALUATION: Uses the same metrics (F-max, S-min) as
     the Critical Assessment of Functional Annotation (CAFA) challenge,
     enabling direct comparison with published methods.

  5. STATISTICAL RIGOR: Includes paired statistical tests, bootstrap
     confidence intervals, and multiple testing correction for
     publication-quality significance claims.

  6. END-TO-END FRAMEWORK: From raw data download to interactive
     prediction dashboard, the entire pipeline is automated and
     reproducible.

  7. EXPLAINABILITY: Multiple interpretation methods (attention weights,
     integrated gradients, GNN explainer) provide biological insights
     into model behavior.

  8. PRACTICAL DEPLOYMENT: The Streamlit dashboard and inference API
     make the model immediately usable for biologists without ML expertise.
